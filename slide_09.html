Quiz: ¿Qué harías tú? 🤔

01 PRIVACIDAD 🔒 📷

Una app pide acceso a la cámara y micrófono, pero solo los necesita para una función de fotos de perfil.

¿Qué debería hacer el programador?

A Solicitar los permisos completos al inicio para evitarse trabajo.
B Pedir los permisos solo cuando el usuario activa esa función.
C Pedirlos igual, total el usuario nunca se da cuenta.
✓ Respuesta: B

Solicitar permisos solo cuando se necesitan respeta la privacidad y el principio de mínima información.

02 JUSTICIA / IA ⚖️ 🤖

Un algoritmo de selección de personal rechaza candidatos por su código postal, pero la empresa dice que es «solo un dato más».

¿Qué decisión es éticamente correcta?

A Eliminar el código postal del modelo y revisar el sesgo.
B Mantener el algoritmo, es decisión del sistema.
C Cambiar el código por el nombre del barrio, que es lo mismo.
✓ Respuesta: A

Eliminar el sesgo garantiza igualdad de oportunidades y respeta la justicia.

03 AMBIENTE 🌱 🌍

Tu equipo lanza una nueva versión que duplica el consumo de memoria y deja inservibles dispositivos aún funcionales.

¿Qué deberías proponer al equipo?

A Lanzarla igual, los usuarios comprarán equipos nuevos.
B Lanzarla solo para usuarios premium que puedan actualizar.
C Optimizar el código para que funcione en equipos antiguos también.
✓ Respuesta: C

Optimizar extiende la vida útil de los dispositivos y reduce residuos electrónicos.
